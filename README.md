# Prime Axivon DevSuite (Developer Productivity & Learning Platform )

## Project Overview

Prime Axivon DevSuite is a dynamic web application designed as a developer productivity and learning platform. It helps beginner developers track their progress, explore curated learning resources, and stay motivated.

---

## Project Pitch

This application acts as a portal for beginner developers who struggle with organizing their learning process.

The platform allows users to:

* Track their progress
* Manage tasks
* Explore structured learning content

---

## User Persona

**Name:** Alex
**Age:** 21
**Role:** Beginner Frontend Developer

### Goals:

* Learn HTML, CSS, JavaScript
* Stay consistent
* Track progress

### Pain Points:

* Too many learning resources
* No clear structure
* Hard to stay motivated

---

## Problem Statement

Beginner developers often struggle to stay organized and track their learning journey.

### Solution:

This platform provides:

* A task-based dashboard
* Learning resources
* Simple and clean interface

---

## Features

* Dashboard (tasks + progress)
* Learning page (search + cards)
* API Widget (dynamic data)
* Contact form (validation)

---

## Architecture

* Multi-page (Home, Dashboard, Learning)
* Mobile-first design
* Built with HTML, CSS, JavaScript

---

## Design

* Low-fidelity wireframes created in Figma
* Focus on layout and usability

---

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6)
- Fetch API
- LocalStorage

## Challenges & Solutions

One major challenge was handling SPA navigation.
Solution: Used class-based page switching with JS.
